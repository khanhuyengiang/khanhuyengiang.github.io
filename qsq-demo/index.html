One noisy \(\sqrt{X}\) gate, many ways to benchmark it

Draw a realistic noise configuration for a simulated superconducting qubit, then estimate the fidelity of its \(\sqrt{X}\) gate with randomised benchmarking (RB), Quantum System Quizzing (QSQ), quantum process tomography (QPT) and gate set tomography (GST), and compare each estimate with the truth.

How QSQ works

QSQ runs a handful of short circuits that repeat the gate, records how often each one ends in the wrong outcome, and hands those failure rates to a machine-learning model. The model was trained beforehand on classical simulations of many noise models, where the true gate is known, and returns the gate's Pauli transfer matrix (PTM), from which its fidelity follows.

Draw a noise configuration

Each draw has amplitude damping, dephasing and readout error, as a provider would report them, plus one hidden gate error that no calibration report shows. Less noise draws \(\sqrt{X}\) infidelities up to \(5\times10^{-3}\), as on current hardware (median about \(9\times10^{-4}\)); more noise draws \(5\times10^{-3}\text{–}10^{-2}\), above that range, so the errors are easier to see in the matrices; its QSQ models are trained up to \(10^{-2}\).

    Pauli transfer matrices

    All matrices are in the gate's own Schur frame, which for \(\sqrt{X}\) is the usual \(I, X, Y, Z\) basis. PTM shows each estimate next to the ideal and true matrices; PTM residual shows each estimate minus the true matrix, on its own colour scale. RB has no PTM. QSQ cannot see the sign of the over-rotation entry \(a\) (the \(YY\) and \(ZZ\) entries), so its panels show \(|a|\) and are compared with the truth folded the same way.

    What to look for

    • QPT assumes perfect state preparation and readout, so readout error ends up in the gate and it usually reports a far worse gate than the true one. Long-sequence QPT repeats the gate up to 257 times, which spreads that error thinly.
    • GST fits preparation, readout and gates together. Both GST designs repeat germs up to 256 times; the reduced one (fiducial pair reduction, what labs usually run) keeps only the fiducial pairs each germ needs, 182 circuits instead of 964, so a fixed total budget gives each circuit about five times more shots.
    • RB ignores readout error, but its per-gate number averages \(\sqrt{X}\) with \(\sqrt{Y}\). A coherent over-rotation of \(\sqrt{X}\) makes interleaved RB overestimate the error.
    • QSQ sets differ only in which circuits they run (see How QSQ works): a minimal basic set (\(e\), \(\sqrt{X}^2\), \(\sqrt{X}^4\)), the same plus three short \(H\) sequences (\(H^2\), \(H\sqrt{X}H\), \(\sqrt{X}H\sqrt{X}\)), the best 16 and best 30 found by a greedy search, the best 16 with shorter sequences preferred, a structured ladder of lengths, and a 26-sequence baseline.
