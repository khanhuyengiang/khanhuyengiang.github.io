# khanhuyengiang.github.io

Personal website, served by GitHub Pages as plain static files (no build step).

- `index.html`: academic homepage and CV (styles in `assets/css/academic.css`)
- `play.html`: the playground, side projects and informal CV (pixel design system in `assets/css/play.css`, sprites and theme toggle in `assets/play.js`)
- `assets/Khanh_Giang_CV.pdf`: the downloadable CV. Replace it when the CV changes, since `.cv/` is gitignored.

Preview locally with `python3 -m http.server` and open http://localhost:8000.

Placeholders to fill in are marked with `TODO` or `href="#"`.
