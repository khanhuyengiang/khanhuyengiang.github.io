2 · Ingredients

One box per ingredient. Press Enter inside a box for a second line, like “(diced)”.

    3 · Steps

    Each step is a column. Click the ingredients a step uses (shift-click picks a range). Things done at the same time, like melting butter while you whisk the flour, go in the same step as separate actions.

    4 · Groups optional

    Label a run of ingredients, like “Crust” and “Filling”. The label runs down the left edge of the table.

    5 · Table

    reorders the ingredients so each step and group stays in one piece
